# FocusFlow

A responsive frontend concept for the Acdyon Technologies Premium Home Page challenge.

## Run locally

Open `index.html` in a browser, or use any static-site preview tool. No build step or package installation is required.

## Included

- Responsive homepage designed for 390px mobile and 1440px desktop.
- Interactive task-plan demo with progress updates.
- Optional Konami-code Easter egg (also available through the footer star).
- `DECISIONS.md` documenting the approach, trade-offs, and AI use.
